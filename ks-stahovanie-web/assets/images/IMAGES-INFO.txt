================================================================================
IMAGE REQUIREMENTS
================================================================================

LOGO (logo.png):
- Recommended size: 180x60px
- Format: PNG with transparent background preferred
- Should be clear and readable at small sizes

SLIDER IMAGES (slider/*.jpg):
- Recommended size: 1920x600px (minimum 1200x400px)
- Format: JPG, optimized for web
- Should show: moving trucks, workers in action, satisfied customers
- High quality but compressed (target: <200KB per image)

VEHICLE PHOTOS (vozidla/*.jpg):
- Recommended size: 800x600px
- Format: JPG
- Show your actual moving trucks/vans
- Clean, professional photos

GALLERY PHOTOS (prace/*.jpg):
- Recommended size: 800x600px
- Format: JPG
- Show real work: loading, carrying furniture, packed items
- Each should demonstrate professionalism and care

================================================================================
IMAGE OPTIMIZATION TIPS
================================================================================

1. Compress all images before uploading
   - Use tools like TinyPNG, ImageOptim, or Squoosh
   - Target: 70-80% quality for JPG

2. Use descriptive filenames with keywords
   - Good: stahovanie-humenne-dodavka.jpg
   - Bad: IMG_1234.jpg

3. Include keywords in alt text (already done in the code)

4. Responsive images:
   - The website uses srcset for responsive images
   - Provide 1x and 2x versions if possible

================================================================================
HOW TO REPLACE PLACEHOLDER IMAGES
================================================================================

1. Prepare your images according to the specs above
2. Name them exactly as shown in the directory structure
3. Upload to the respective folders
4. No code changes needed - images will automatically display
